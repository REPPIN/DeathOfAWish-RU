# Death of a Wish — русский перевод

Неофициальный русский перевод игры **Death of a Wish** (Unity, 2019.4). Перевод не проверен в игре целиком, см. «Известные проблемы».

Репозиторий **не содержит файлов игры**. Перевод ставится в вашу установку скриптом.

## Что внутри

- `ru/chunk_00.json` … `ru/chunk_11.json` — русский текст, 4572 строки. Ключи совпадают с английской локализацией игры.
- `scripts/patch.py` — ставит перевод в папку игры.
- `fonts/` — шрифты [Stalinist One](https://fonts.google.com/specimen/Stalinist+One) и [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P), лицензия SIL OFL (тексты в `fonts/OFL-*.txt`).
- `GLOSSARY.md` — глоссарий терминов, которым следовал перевод.
- `LICENSE` — MIT для перевода и скриптов. На игру и её ассеты эта лицензия не распространяется.

## Что меняет патч

- `DeathOfAWish_Data/sharedassets0.assets`:
  - в локализацию `Lucah_Localization_ES` записывается русский текст;
  - шрифт `xirod` заменяется на Stalinist One, `Pokemon GB` на Press Start 2P.
- `DeathOfAWish_Data/level0`: подпись «Español» в меню языка становится «Русский».

## Установка

1. Установите Python 3.10 или новее.
2. Установите зависимости:
   ```
   pip install UnityPy==1.25.4 TypeTreeGeneratorAPI
   ```
3. Запустите патч, передав папку игры (та, где лежит `DeathOfAWish.exe`):
   ```
   python scripts\patch.py "C:\Games\Death of a Wish"
   ```
4. Запустите `DeathOfAWish.exe`, в меню языка выберите «Русский».

При первом запуске скрипт сохраняет оригиналы `sharedassets0.assets` и `level0` в папку `backup` внутри папки игры. Патч всегда берёт файлы из `backup`, поэтому его можно запускать повторно.

## Откат

Скопируйте `sharedassets0.assets` и `level0` из папки `backup` обратно в `DeathOfAWish_Data`.

## Известные проблемы

- Игра не проверялась целиком. Длинные строки в меню и подсказках могут не помещаться: новые шрифты отличаются по размеру от старых.
- Строки с `PLAYERNAME` в некоторых местах используют мужские окончания.
- Несколько строк с `TARGET` переведены с сохранением этого слова отдельно, поэтому звучат суше оригинала.
- Названия треков и часть терминов выбраны без официального источника, см. `GLOSSARY.md`.
- Заголовок игры переведён как «Смерть желания». Если нужно оставить английское название, это правится в `ru/chunk_01.json` (ключи `title_christian`, `dw_teaser_end_00`, `ui_music_doaw`).

## Для разработчиков

Перевод хранится в JSON `{"key": "перевод"}` по частям. Ключи берутся из `Lucah_Localization_EN` внутри игры и сверяются при патче. Плейсхолдеры `{EQUIP}`, `[PLAYERNAME]`, `TARGET`, переносы `\n` и теги `<color=...>` должны сохраняться как в оригинале.
