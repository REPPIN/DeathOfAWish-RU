# Death of a Wish — русский перевод

Неофициальный русский перевод игры **Death of a Wish** (Unity, 2019.4). Перевод пока не проверен в игре целиком, см. «Известные проблемы».

Репозиторий **не содержит файлов игры**. Перевод применяется к вашей копии игры скриптом.

## Что внутри

- `ru/chunk_00.json` … `ru/chunk_11.json` — русский текст, всего 4572 строки. Ключи совпадают с английской локализацией игры.
- `scripts/patch.py` — копирует игру в папку «<игра> - RU» и вносит в копию перевод, шрифт и подпись языка.
- `fonts/RussoOne-Regular.ttf` — шрифт Russo One (лицензия SIL OFL, текст в `fonts/OFL.txt`).
- `GLOSSARY.md` — глоссарий терминов, которым следовал перевод.

## Что меняет патч

- В `DeathOfAWish_Data/sharedassets0.assets` в локализацию `Lucah_Localization_ES` записывается русский текст. Русский выбирается в меню как язык «Русский» (слот ES).
- Шрифты `xirod` и `Pokemon GB` заменяются на Russo One, потому что старые шрифты не содержат кириллицы.
- В `DeathOfAWish_Data/level0` подпись «Español» в меню языка меняется на «Русский».

Оригинальная папка игры не меняется.

## Установка

1. Установите Python 3.10 или новее.
2. Установите зависимости:
   ```
   pip install UnityPy==1.25.4 TypeTreeGeneratorAPI
   ```
3. Скачайте репозиторий и запустите патч, передав путь к папке игры (папка с `DeathOfAWish.exe`):
   ```
   python scripts\patch.py "C:\Games\Death of a Wish"
   ```
4. Запустите `DeathOfAWish.exe` из новой папки `C:\Games\Death of a Wish - RU`.
5. В меню языка выберите «Русский».

Чтобы вернуть игру в исходное состояние, удалите папку «- RU». Оригинал не затрагивается.

Скрипт не запускается, если папка «<игра> - RU» уже существует. Удалите её или переименуйте, прежде чем запускать патч снова.

## Известные проблемы

- Игра не проверялась целиком. Длинные строки в меню и подсказках могут не помещаться, потому что Russo One отличается по размеру от старых шрифтов.
- Строки с `PLAYERNAME` в некоторых местах используют мужские окончания.
- Несколько строк с `TARGET` переведены с сохранением этого слова отдельно, поэтому звучат суше оригинала.
- Названия треков и часть терминов выбраны без официального источника, см. `GLOSSARY.md`.
- Заголовок игры переведён как «Смерть желания». Если нужно оставить английское название, это правится в `ru/chunk_01.json` (ключи `title_christian`, `dw_teaser_end_00`, `ui_music_doaw`).

## Для разработчиков

Перевод хранится в JSON с полями `{"key": "перевод"}` по частям. Ключи взяты из `Lucah_Localization_EN` и сверяются при патче. Строки с плейсхолдерами `{EQUIP}`, `[PLAYERNAME]`, `TARGET`, а также переносы `\n` и теги `<color=...>` должны сохраняться как в оригинале.
